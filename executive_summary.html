Strategic Context: Why Now?

도입 배경 및 페인포인트 비교

Current-State Drag (Pre-AI)

기존 업무 환경의 문제점

  • Fragmented Silos: Employees context-switch across WorkWeek, ServiceImmediately, and static PDFs.
  • 48h–72h Delays: Routine address updates, leave approvals, and equipment orders suffer long queues.
  • High Operational Spend: 12,500+ monthly Tier 1 tickets consume $150K/month in shared-services labor.
  • 14.5% Policy Error Rate: Ambiguous handbooks result in misinterpretations and re-opened tickets.
  • 시스템 단절: WorkWeek, ServiceImmediately, 50쪽 분량의 사규 PDF 사이의 잦은 화면 전환.
  • 48~72시간 대기: 단순 주소 변경, 연차 잔여일 확인, 장비 신청 처리에 며칠씩 소요.
  • 과도한 운영비: 월 12,500건의 단순 문의 처리로 월 $150,000 이상의 운영 인건비 소모.
  • 14.5% 재문의율: 복잡한 연차/휴직 규정 오해로 인한 반복 질의 및 컴플라이언스 오류 발생.

Autonomous AI Operations (Post-AI)

자율형 에이전트 도입 후 혁신

  • Unified Interface: Single natural conversational gateway for all HR, IT, and policy requests.
  • Sub-3.5s Self-Service: Real-time API execution with immediate verification feedback.
  • 40% Deflection: Over 5,000 tickets automated monthly, shifting staff to strategic casework.
  • 0.0% Hallucination: Deterministic OKF ontology rules eliminate policy miscalculations.
  • 단일 대화 창구: 자연어 대화 한 줄로 인사 정보 조회, IT 티켓 신청, 사규 확인 원스톱 해결.
  • 3.5초 즉각 완결: 실시간 백엔드 연동을 통한 대기 시간 제로화 및 실시간 승인 확인.
  • 40% 티켓 감축: 매달 5,000건 이상의 업무를 자동 처리하여 고부가가치 프로젝트에 집중.
  • 0% 규정 오적용: OKF 시맨틱 지식 엔진을 통한 수치적·법적 판단의 100% 무결성 보장.

Technical Reliability & Architectural Pillars

기술적 차별성 및 신뢰성 아키텍처

🧠

OKF Tri-Hybrid Brain

OKF 트라이-하이브리드 브레인

Combines Dense Vector + Lexical BM25 + Open Knowledge Format (OKF) Semantic Ontologies. Evaluates multi-conditional leave matrices (Singapore SPL, childcare tiers) with 0% hallucination.

벡터 검색 + 키워드 검색(BM25) + OKF 시맨틱 온톨로지를 삼중 결합하여 싱가포르 복합 출산/육아휴직 및 근속 연수별 연차 매트릭스를 0% 환각으로 판정합니다.

Zero Hallucination
⚙️

Deterministic Middleware

결정론적 검증 미들웨어

Decouples LLM generation from database execution. A Python rule engine validates date sanity (start ≤ end), balance availability, and leave units before API execution.

생성형 AI가 DB를 임의로 조작하지 못하도록 파이썬 검증 엔진이 날짜 유효성, 실시간 연차 잔여 한도, 반일/전일 규격을 선검증한 후 안전하게 API를 호출합니다.

Mathematical Integrity
🔄

Durable Saga Coordinator

분산 트랜잭션 사가 코디네이터

Firestore state & Cloud Tasks orchestrate multi-step workflows (e.g. $500 home office equipment, leave + email delegation) with automated compensation and zero split-brain.

Cloud Firestore 상태 관리와 Cloud Tasks를 기반으로 장비 지원, 휴직 시 이메일 위임 티켓 발행 등 이종 시스템 간 트랜잭션을 롤백 기능과 함께 무결하게 처리합니다.

Split-Brain Immunity
🛡️

Google SAIF Zero-Trust

Google SAIF 기반 제로트러스트

<15ms heuristic regex pre-filters for 100% prompt injection blocking, Cloud DLP log redaction for sensitive PII/medical data, and CMEK encryption at rest.

15ms 미만의 인라인 정규식 필터로 프롬프트 주입 공격을 원천 차단하고, Cloud DLP로 민감 개인정보(SPII)를 자동 비식별화하며 고객 관리 키(CMEK)로 암호화합니다.
